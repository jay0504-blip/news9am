# news9am — 매일 오전 9시 아침 뉴스 릴스 자동 게시

매일 아침 07:00(한국시간)에 자동으로 시작해서 **오전 9:00:00 정각**에 인스타그램 `@news_9am`에 릴스를 올립니다.

## 하는 일
1. 구글 뉴스에서 오늘의 큰 이슈 수집
2. 무료 AI(Gemini)가 편한 말투로 대본 작성 → 다른 AI 호출로 **사실 검수**(근거 없는 문장은 고치거나 삭제)
3. 위키미디어 공용 사진 후보 → AI가 사진을 직접 보고 **검수**(사람 얼굴·엉뚱한 사진 제외). 맞는 사진이 없으면 움직이는 이모지 장면
4. 1.5배속 음성 + 자막 + 영상 합성 → **자동 점검**(길이·소리·화면·용량)
5. GitHub Pages에 영상 올리고 인스타 게시 준비 → **9:00:00에 게시** → 게시 확인

## 안전장치
- 07:00 실행이 빠지면 07:40 예비 실행 (하루 두 번 올라가지 않음)
- AI가 붐비면 30분까지 재시도, 그래도 안 되면 기사 제목만으로 만든 안전한 대본
- 사진 검수가 늦어지면 이모지 장면으로 바꿔 9시 전에 반드시 완성
- 실패하면 GitHub이 가입 메일로 알림

## 직접 해볼 수 있는 것 (Actions → 아침 뉴스 자동 게시 → Run workflow)
- `test` : 영상만 만들기 (게시 안 함)
- `prepare` : 게시 직전까지 시험 (게시 안 함)
- `now` : 지금 바로 게시
- `normal` : 9시에 게시

## 멈추고 싶을 때
Actions → 아침 뉴스 자동 게시 → 오른쪽 위 `···` → **Disable workflow**

만든 영상은 각 실행 화면의 Artifacts에서 7일간 내려받을 수 있습니다.
